The method

A Flox environment is one file.

The tools, the settings, and the services a project needs.

Every machine that activates it gets the same thing.

Read the slide; this is the one sentence they should remember.

How it feels

Your machine, plus the project.

Hollow Manor's tools & settings flox activate

Your OS: macOS or Linux unchanged

No container to build.

Leave the project, and the layer goes with you.

"No container to build, no VM. You keep your shell, your editor, your dotfiles. Flox layers the project's tools on top while you're in the project, and takes them away when you leave."

Under the floorboards

Beneath Flox, there is Nix.

Every package is built in isolation, from inputs that are hashed.

Each build gets its own address. Versions never overwrite each other.

Flox gives you that, without learning the Nix language.

Where tonight's Python actually lives

/nix/store/
65p6ipj712fb5igr9w1h5k
5cb7bymj42-python3-3.12.13

Change any input, and the hash changes with it.

"How can Flox promise the same thing on every machine? Underneath is Nix, a package manager that started as research at Utrecht University twenty years ago, and Nixpkgs is one of the largest package collections in the world."

"Nix builds every package in isolation and names it by a hash of everything that went into it. That path is where the game's Python lives on this laptop. Same inputs, same hash, on any machine."

"Nix is powerful and famously hard to learn. Flox keeps the guarantees and gives you a TOML file and a handful of commands instead."

"There it is, in my shell history, for good. The deploy docs pass it on the docker run command line, which is worse. The repo already gitignores .env. Nothing reads it."

flox edit, paste talk/snippets/1-vars-and-hook.toml, save.

The rule

Settings are shared. Secrets are loaded.

[vars]: committed, shared

[vars]
PORT = "8666"
DAILY_BUDGET_USD = "2"

[hook]: reads .env, never shared

[hook]
on-activate = '''
  set -a
  . "$FLOX_ENV_PROJECT/.env"
  set +a
'''

A secret never goes in the manifest.

"[vars] is for settings, like the port and the daily budget. They're committed, so everyone shares them. Secrets get loaded by the hook from a .env file that never leaves your machine. The manifest is shared, and can go to FloxHub, so a secret never goes in it."

Slide shows the hook simplified; the real one also checks the file exists and warns when the key is missing.

flox activate, echo "$DAILY_BUDGET_USD", exit.

Clue 3

The server nobody managed.

python3 server.py lives and dies with one terminal tab.

[services.manor]
command = 'python3 "$FLOX_ENV_PROJECT/server.py"'
$ flox activate --start-services
$ flox services logs manor --follow

"Close the tab, lose the game, lose the logs."

flox edit, paste talk/snippets/2-services.toml, save. Then the two commands (plus flox services status if on time).

Browser: localhost:8666, Enter the Manor, ask Zora "Did anyone leave the séance early?" Point at the log. 60 seconds max.

"The environment runs the server for me, with the settings and the key already loaded." Ctrl-C, exit.

The accusation

A clean machine. One command.

$ git clone https://github.com/justincastilla/hollow-manor-mystery-II.git
$ cd hollow-manor-mystery-II
$ flox activate --start-services

No clone at all? flox push, then flox activate -r.

Second machine. The hook prints the .env.example hint: "A brand-new teammate, and the environment tells them exactly what's missing."

exit, cp .env.example .env, paste the key, activate again, open the game.

"You don't even need the clone: flox push sends the environment to FloxHub, and anyone on the team runs flox activate -r to step into it."

Postscript

Your agents are new teammates, too.

They read

One file

The manifest lists every tool, setting, and service. Nothing to guess.

They run

One command

flox activate -- pytest runs inside the environment, no prompt needed.

They change

Nothing else

An agent's flox install lands in the project, shows up in the diff, and rolls back with git.

"Everything that helps a new teammate helps an AI coding agent even more. An agent can't ask you which Python you meant. It reads the manifest and knows."

"It runs commands with flox activate, double dash, the command, so tests and servers run with the project's tools. And when it installs something, it goes into the project environment, not your laptop, where you can review it like any other change."

"When I prepped this talk, an agent got this game running from the repo with flox activate, and the only thing it had to ask me for was the key."
